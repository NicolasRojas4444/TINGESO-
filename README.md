# SIGA IPT

SIGA IPT is an academic management system for the Instituto Profesional de
Tecnología. It centralizes student and teacher records, degree programs, study
plans, courses, prerequisites, academic periods and class schedules.

Students can register for courses, view their curriculum and weekly schedule,
and consult their academic history. Teachers manage final grades for their
assigned sections, while academic administrators manage the catalog and close
academic periods.

The project uses React, Vite and TypeScript for the interface, Java and Spring
Boot for the application logic, PostgreSQL for persistence, and Keycloak for
authentication and role-based access. It follows a layered monolithic architecture.
